Aircraft database (registration & type)

Plain dump1090-fa and the SBS feed don't include registration or aircraft type per plane — only readsb/tar1090 do. VliegmasjienPRO fills the gap automatically: each new aircraft is looked up once and cached here, so the list, type filters and statistics fill in over time. To load a whole database at once (e.g. if your receiver has no internet), import a CSV/NDJSON below.

—

Communication frequencies (map layer)

Toggle the 📻 Freqs layer on the map to see airport radio frequencies (tower, ground, approach, ATIS…) near your view. Data is the public-domain OurAirports dataset — download it once below (a few MB), then it's served locally and offline.

—

Range outline (map layer)

Your receiver's actual coverage shape, built from the farthest aircraft seen in each direction. It grows and refines the longer the app runs. Toggle it from the map's Layers ▸ Range outline.

—

Weather

Rain radar (RainViewer) works out of the box. For cloud/precipitation/wind layers, add a free OpenWeatherMap API key.

Sky Watch (stargazing)

Set the light-pollution level at your location on the Bortle scale so the Sky Watch tab can estimate what's visible. Not sure? Check a light-pollution map (e.g. lightpollutionmap.info). Cloud & Moon data are automatic.

Aeronautical layers

The 🛫 Airspace overlay (controlled airspace, CTR/TMA/CTA…) uses OpenAIP — get a free API key from your OpenAIP account (My Account → API Keys) and paste it here. The 🌬 Aviation weather (METAR) layer uses aviationweather.gov and needs no key. Toggle both from the map's Layers menu.
